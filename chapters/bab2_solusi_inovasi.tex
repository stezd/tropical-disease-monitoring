\section{Solusi dan Inovasi\\yang Ditawarkan}

\subsection{Deskripsi Solusi dan Alur Klinis Berjenjang}

TropiCare dirancang sebagai platform triase mandiri pra-hospital berbasis \textit{Progressive Web App} (PWA) yang mengedepankan keselamatan pasien (\textit{safety-first}) dan kepatuhan mediko-legal. Seluruh alur penalaran klinis mengacu ketat pada KMK No. HK.01.07/MENKES/1186/2022 tentang Panduan Praktik Klinis bagi Dokter di FKTP \citep{Kemenkes2022a} serta Permenkes No. 3 Tahun 2026 tentang Penanggulangan Penyakit \citep{Permenkes2026}. Sistem menyaring kondisi pasien melalui empat lapisan klinis berurutan:

\begin{enumerate}
    \item \textbf{Lapisan 1 -- Gerbang Privasi \& Evaluasi 11 Tanda Bahaya Sisi Klien (\textit{Client-Side Red Flags}):} 
    Sebelum kuesioner dimulai, pengguna wajib mencentang persetujuan privasi (\textit{informed consent}). Selanjutnya, sistem mengevaluasi 11 indikator kegawatdaruratan mutlak (\textit{Primary Survey}): syok hipovolemik dengue (akral dingin, nadi filiform), perdarahan saluran cerna masif, gagal ginjal akut (anuria), distres pernapasan berat, penurunan kesadaran/kejang, dehidrasi berat, luka gigitan hewan penular rabies (GHPR), sindrom koroner akut (\textit{Code STEMI}), stroke akut (SeGeRa Ke RS), krisis hipertensi ensefalopati, dan koma diabetik \citep{Kemenkes2022a}. Satu saja tanda bahaya terkonfirmasi, sistem seketika memutus kuesioner dan melompat ke Rute Merah. Evaluasi ini dieksekusi 100\% di peramban (\textit{in-browser}) dalam waktu $<500\text{ ms}$ tanpa menunggu komunikasi jaringan peladen.
    
    \item \textbf{Lapisan 2 -- Pemetaan Gejala Sindromik Dinamis \& Determinan Spasio-Ekologis \textit{One Health}:} 
    Bagi pasien non-darurat, sistem memilah keluhan ke dalam 5 klaster infeksi tropis (demam vektor/zoonosis, saluran napas/dada, pencernaan/hepatobilier, kulit/mukosa, pembengkakan ekstremitas) dan 3 klaster kronis PTM (gula/saraf, tekanan darah/vaskular, sendi/gout) \citep{PERKENI2024}. Sistem memadukan determinan spatio-ekologis \textit{One Health}: riwayat kawasan endemis (Lembah Napu/Lindu untuk Skistosomiasis, Indonesia Timur untuk Malaria dan Frambusia), paparan banjir untuk Leptospirosis, hunian padat untuk TBC/Skabies, serta kontak vektor lingkungan \citep{Permenkes2026}.
    
    \item \textbf{Lapisan 3 -- Farmakovigilans Obat Aktif \& Proksi Fisik Tanpa Alat Medis:} 
    Untuk mencegah keparahan swamedikasi bebas, sistem menerapkan 5 pemicu keamanan obat: kontraindikasi mutlak NSAID (Ibuprofen/Aspirin) pada suspek dengue yang memicu perdarahan lambung masif \citep{Alam2022,Mohiuddin2023,Tovar2024}; larangan antimotilitas (Loperamide) pada disentri yang memicu \textit{toxic megacolon} \citep{Koo2007,Schiller2020}; serta diferensiasi efek samping obat rutin (edema Amlodipine vs filariasis \citep{Liang2022,Savage2020,Sica2003} dan batuk Captopril vs TBC \citep{Dicpinigaitis2014}). Mengatasi minimnya alat medis rumah tangga \citep{Kemenkes2024}, sistem menyediakan proksi fisik: menggigil gemetar (\textit{rigors}) sebagai proksi demam tinggi, denyut nadi istirahat sebagai proksi takikardia, pakaian melonggar drastis sebagai proksi malnutrisi/hiperkatabolisme (IMT $<18,5\text{ kg/m}^2$), dan celana menyempit sebagai proksi obesitas sentral \citep{PERKENI2024}.
    
    \item \textbf{Lapisan 4 -- Orkestrasi 4 Rute Rujukan Medis dan Navigasi Faskes Presisi:} 
    Sistem menetapkan status triase ke dalam empat rute: \textbf{Rute Merah} (IGD/119, aktivasi sirene visual dan instruksi Bantuan Hidup Dasar); \textbf{Rute Kuning Khusus} (Poli Program Nasional Kemenkes: TBC, Kusta, Frambusia, Filariasis, Skistosomiasis dengan navigasi faskes penyedia obat program OAT/\allowbreak MDT/\allowbreak Praziquantel); \textbf{Rute Kuning} (Puskesmas/Klinik Pratama dengan mandat puasa 10--12 jam sebelum uji lab glukosa/lipid \citep{PERKENI2024}); serta \textbf{Rute Hijau} (Perawatan Mandiri/Apotek untuk kasus ringan SKDI 4A).
\end{enumerate}

\begin{enumerate}
    \item \textbf{Lapisan Komputasi Tanpa Status (\textit{Stateless Shared-Nothing}):} 
    Triase publik TropiCare beroperasi murni bebas status \citep{Kleppmann2017}. Vektor gejala dikirim mandiri tanpa ketergantungan sesi peladen. Pod FastAPI berjalan di atas Kubernetes multi-wilayah dengan \textit{Horizontal Pod Autoscaler} (HPA), mereplikasi simpul komputasi secara elastis saat terjadi lonjakan beban puncak KLB.
    
    \item \textbf{Partisi Geospasial Konsisten (\textit{Consistent Hashing}):} 
    Data regional dipartisi melintasi 3 zona makro (WIB, WITA, WIT). Algoritma \textit{Consistent Hashing} berbasis MurmurHash3 mendistribusikan beban secara merata dan mengisolasi titik panas kueri (\textit{hot-spots}) saat terjadi wabah lokal di suatu daerah \citep{Kleppmann2017}.
    
    \item \textbf{Replikasi Asinkron Direktori 13.930 Faskes SATUSEHAT MSI:} 
    Dengan rasio baca-tulis $>10.000 : 1$, sistem menerapkan \textit{Single-Leader Multi-Follower Replication} \citep{Kleppmann2017} pada PostgreSQL + PostGIS, dipadukan dengan \textit{in-memory cache} Redis Geospatial (`GEOSEARCH`) berlatensi $<1\text{ ms}$. Salinan direktori terkompresi Brotli (1,2 MB) disimpan di peramban untuk kalkulasi jarak Haversine luring.
    
    \item \textbf{Hierarki Inferensi Model Medis Bertingkat (\textit{Tiered Model Serving}):} 
    Mencegah inefisiensi biaya awan, sistem menerapkan empat tingkat eksekusi: \textit{Tier 0} (WASM/JS in-browser untuk 11 Red Flags dan 5 pemicu farmakovigilans; $<500\text{ ms}$, 0 USD biaya awan); \textit{Tier 1} (CPU Pods untuk mesin aturan dan temu balik leksikal BM25 terhadap KMK 1186/2022; $<20\text{ ms}$); \textit{Tier 2} (GPU vLLM Cluster dengan model terkuantisasi MedGemma/\allowbreak BioMistral 4-bit AWQ menggunakan \textit{PagedAttention} yang melenyapkan fragmentasi memori KV cache \citep{Kwon2023}, \textit{Continuous Batching}, dan \textit{Static Prefix Caching} teks regulasi yang melipatgandakan \textit{throughput} $4\times - 8\times$); serta \textit{Tier 3} (antrean asinkron Kafka/Celery untuk audit kasus langka).
    
    \item \textbf{Pemrosesan Aliran Data \& Surveilans Epidemiologi Real-Time:} 
    Triase tuntas memancarkan telemetri anonim (Zero-NIK: sindrom, usia, gender, wilayah) ke Apache Kafka / Redpanda \citep{Kleppmann2017}. Mesin pemroses aliran Apache Flink menghitung deret waktu jendela bergeser (1--6 jam) untuk mendeteksi lonjakan kasus dan memicu peringatan dini ke SKDR Ditjen P2P Kemenkes RI.
    
    \item \textbf{Kedaulatan Data, Kerahasiaan Zero-NIK, dan Handover Luring:} 
    TropiCare tidak menyimpan NIK di peladen pusat. Hasil triase dikompresi ke gambar kode matriks dua dimensi (\textit{2D QR Code}) di peramban sebagai kantung data terdistribusi. Nakes loket Puskesmas memindai QR Code untuk menginjeksi data klinis terstruktur (HL7 FHIR R4) ke SIMPUS dalam $<1$ detik tanpa ketik ulang (\textit{zero-retyping}).
\end{enumerate}
